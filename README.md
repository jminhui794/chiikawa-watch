# 치이카와 극장판 상영 감시기

`극장판 치이카와: 인어 섬의 비밀` (2026-09-30 개봉)의 **9/19~9/20 사전 상영회**를
감시해서 새 회차가 열리거나 취소표가 나오면 **Windows 토스트 알림**을 띄운다.

## 동작

5분마다 4개 체인을 조회하고, 직전 결과(`state.json`)와 비교해 변화가 있을 때만 알림.

| 체인 | 방식 | 감지 범위 |
|---|---|---|
| 롯데시네마 | `GetPlaySequence` API | 회차 + **잔여좌석** (취소표 감지 가능) |
| 메가박스 | `selectBokdList.do` API | 날짜별 **편성 여부**만 (좌석수 미제공) |
| 씨네큐 | 영화 상세페이지 DOM | 지점별 **상영예정 여부**만 |
| CGV | — | **미지원** (아래 참고) |

알림 종류
- 🎬 **새 회차 오픈** — 직전에 없던 회차가 생김
- 🎟️ **취소표 발생** — 잔여 0석이던 회차에 자리가 남 (롯데만 가능)

## 실행

이미 **시작프로그램에 등록**되어 있어 로그인하면 자동으로 뜬다.
(`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\ChiikawaWatch.vbs`)

```powershell
# 수동 1회 실행 (콘솔에서 결과 확인)
python watch.py --once

# 수동 상시 실행
python watch.py

# 중지
Get-Process pythonw | Stop-Process
```

## 설정 — `config.json`

- `watch_dates` — 감시할 날짜 (`YYYYMMDD`). 개봉 후에도 쓰려면 `"20260930"` 등을 추가
- `poll_seconds` — 폴링 주기 (기본 300초)
- 각 체인의 극장 코드는 서울 전역 + 남양주로 채워져 있음

## 알려진 한계

### CGV 미지원 — 실제 조회 성공 확인 필요

2026-09-15 이 PC의 숨김 Chrome으로 CGV 예매 페이지에 접속했을 때,
CGV가 접근 제한 화면을 반환했다. 회차·좌석 응답을 검증하지 못했으며
**CGV 알림 연동은 아직 미완료**다. 기존 문서의 "로그인이 반드시 필요하다"는
결론도 확인되지 않았다.

현재 코드는 CGV 페이지에서 조회를 시도하고 접근 제한, HTTP 오류,
예상과 다른 응답 형식을 오류로 기록한다. 조회 실패 시 이전 CGV 기록을 유지하여
실패 후 복구를 새 회차 오픈으로 오인하지 않도록 했다. 일부 지점만 조회된
경우에도 CGV 전체 기준선을 갱신하지 않는다. 유지된 기록은 최신 조회 결과가 아니다.

일반 Chrome에서 CGV 극장별 상영시간표가 열리는지 확인한 뒤,
정상 화면이 사용하는 회차·잔여좌석 응답을 확인해야 연동을 완료할 수 있다.
로그인만으로 해결된다고 보장할 수 없다.

로그인 상태를 사용하는 조회를 위해 전용 Chrome 프로필을 지원한다.

```powershell
python cgv_session.py
```

열린 창에서 직접 로그인하고 극장별 상영시간표를 확인한 뒤 창을 닫는다.
다음 감시 실행부터 `.cgv-profile`의 로그인 상태를 사용한다.
이 폴더에는 로그인 정보가 저장되므로 공유하지 않는다. 로그인 만료 시 위 명령을
다시 실행한다. 프로필을 동시에 열 수 없으므로 로그인 작업 중에는 감시기를 중지한다.
로그인 프로필 지원은 회차 API 연동 완료를 의미하지 않는다.

실패 처리 검증 (네트워크·알림·상태 파일 변경 없음):

```powershell
python -m unittest -v test_watch
```

### 기타
